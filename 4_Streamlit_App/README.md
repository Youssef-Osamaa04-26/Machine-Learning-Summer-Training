# 🏠 Real Estate Predictor - Streamlit App

## Overview
Interactive web app for Real Estate Price Prediction and Is_Sold Classification.

## Pages
1. 🏠 **Home** - Welcome page
2. 💰 **Price Prediction** - Regression model
3. 📊 **Is_Sold Classification** - Classification model
4. 📈 **EDA Insights** - Data visualizations
5. 🤖 **Models Comparison** - Compare all models
